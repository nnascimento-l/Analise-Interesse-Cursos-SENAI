# Análise de Interesse em Cursos - SENAI

Dashboard interativo em Power BI que analisa o interesse de pessoas em cursos de um Centro de Formação Profissional do SENAI, cruzando informações de cursos, unidades, patrimônio e alunos em um só relatório.

> Projeto acadêmico, sem fins comerciais. Os dados utilizados são fictícios ou anonimizados.

## Objetivo

Apoiar a gestão na decisão de quais cursos ofertar, em quais unidades e em qual período, além de facilitar o controle do patrimônio e o acompanhamento dos alunos, substituindo consultas manuais por painéis visuais com filtros.

## Navegação

O relatório abre em uma capa com botões para cada página, e todas as páginas têm setas no topo para voltar ao menu ou avançar.

## Páginas

Power BI Desktop, Power Query para tratamento dos dados e DAX para as medidas.
